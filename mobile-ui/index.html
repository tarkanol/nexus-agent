⚠️ AGENT ARKA PLANDA ÇALIŞMIYOR? — CRON KURULUMU
Worker kendi kendine order açmak için Cloudflare Cron Trigger gerektirir. wrangler.toml dosyana şunu ekle:
[triggers]
crons = ["*/1 * * * *"] # her 1 dakikada
Sonra wrangler deploy yap. Cloudflare dashboard → Workers → Triggers'dan da ekleyebilirsin.
⚡ Frontend (bu sayfa) açıkken de 5s'de bir refresh yapar, ama sekme kapalıysa sadece Cron çalışır.
Cron yoksa: Scanner sinyallerini görürsün ama Worker otomatik order AÇMAZ. Manuel/auto mode ile frontend'den açabilirsin.
